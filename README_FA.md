# Xunter — تستر حرفه‌ای کانفیگ VPN

> **[English](./README.md)** | **[فارسی](./README_FA.md)**

---

## معرفی

**Xunter** یک ابزار قدرتمند و ماژولار برای تست کانفیگ‌های VPN است که بر پایه **هسته Xray** ساخته شده است.

این ابزار می‌تواند:

- کانفیگ‌های لینک
- و فایل‌های کانفیگ

را به‌صورت **واقعی و دقیق** تست کند و نتیجه را در ترمینال نمایش دهد.

---

## ویژگی‌ها

- پشتیبانی از پروتکل‌های مختلف (vmess, vless, trojan, ss و...)
- پشتیبانی از لینک و فایل
- نمایش زنده نتایج (Live)
- جدول رنگی و خوانا
- سیستم امتیازدهی (Score)
- مولتی‌تردینگ
- کراس‌پلتفرم (ویندوز، لینوکس، مک)
- تست واقعی با Xray
- ذخیره کانفیگ‌های سالم

---

## پیش‌نیازها

- Python 3.10+

- نصب وابستگی‌ها:

```bash
pip install -r requirements.txt
```

---

## نصب

### روش 1: دانلود ZIP

1. دانلود پروژه
2. استخراج فایل
3. اجرای برنامه:

```bash
python hunterx.py
```

---

### روش 2: استفاده از Git

```bash
git clone https://github.com/your-repo/xunter.git
cd xunter
pip install -r requirements.txt
python hunterx.py
```

## تنظیمات (settings.json)

```json
{
    "timeout": 2,
    "test_url": "https://google.com",
    "workers": 3,
    "socks_port_start": 1080
}
```

---

## نکته مهم درباره Workers

- اگر تعداد کانفیگ کم است ➜ مقدار کمتر (مثلاً 5)
- اگر تعداد زیاد است ➜ مقدار بیشتر (مثلاً 20+)

> ⚠️ مقدار زیاد مصرف CPU را بالا می‌برد

---

## افزودن کانفیگ

### روش دستی

ویرایش `configs.json`

---

### روش ساده (پیشنهادی)

